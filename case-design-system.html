Project Overview

There was no published design system, so every feature was designed and built without a common base of colors, typography, spacing, or naming. This showed up directly in implementation, the checkout button could not be reproduced exactly by Shopify's Checkout API, its gradient and border radius had no equivalent, so design and engineering had to negotiate a visual compromise case by case instead of working from a documented spec.

The goal was to fix that at the source, build the foundations first, align naming with engineering before anything got built, and roll out the resulting tokens in phases instead of all at once.

The Framework

Three layers, separating what a value is from what it means from how it gets negotiated when a platform can't render it.

Layer 1
Foundations
Color, type, spacing, opacity, naming, circulated with engineering first
Layer 2
Token Migration
Spacing shipped first, color followed, backed by comparison tables
Layer 3
Negotiated Constraints
Platform limits decided and documented with engineering, not found at build time

Reflection

The design system could specify a value, but not every platform could render it. Shopify's checkout page could only approximate the button token, which meant the gap had to be negotiated and documented with engineering as an accepted exception, not solved by the tokens alone. The same caution applied to typography, a broad type change needed to be reviewed on real screens before rollout, not just approved on paper.

The foundations later became the base for a separate case, feeding an AI content pipeline so vibe-coded marketing pages stay on brand automatically, which only worked because the documentation was solid enough for something other than a human designer to read it.
