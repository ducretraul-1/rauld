# Raúl Ducret | Portfolio

Static site, no build step. Six pages, one shared stylesheet, deployed on Vercel from this repo.

- `index.html`: Home
- `about.html`: About
- `case-direct-response.html`: Touchbase, AI-assisted landing page workflow
- `case-design-system.html`: Design system foundations
- `case-quick-add.html`: Quick Add modal redesign
- `case-quiz.html`: Product quiz UX audit
- `resume.pdf`: Resume, also available at `/cv` and `/resume`
- `styles.css`: tokens, layout, responsive rules

## Updating the resume

Replace `resume.pdf` with the new file (same name) and push. Every link on the site updates at once.

## Analytics

Pages load Vercel Web Analytics. Enable it once in the Vercel dashboard: Project, Analytics, Enable.

## Deploy

Every `git push` to `main` redeploys automatically.
